Mode-sombre

  • Objectif : Créer un bouton qui permet de basculer l'ensemble de la page en "mode sombre".
  • Consignes :
  • Sur cette page HTML, ajouter un bouton, avec comme contenu texte : "Mode sombre" (vous pouvez utiliser des icônes Fontawsome si vous le souhaitez)
  • Au clic sur ce bouton, ajouter si elles n'y sont pas, supprimer si elles y sont les classes CSS ".bg-dark" et "text-light" sur la balise body
  • Modifier le texte du bouton dynamiquement : s'il est en mode clair, afficher "Mode sombre", s'il est en mode sombre, afficher "Mode clair", adaptez les icônes si vous les avez utiliser
