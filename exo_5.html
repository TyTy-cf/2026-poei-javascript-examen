  • Directement dans l'HTML, créer un champ input de type text avec la classe "search-filter"
  • Vous avez une liste d'utilisateur définie sur la même page HTML, dans un ul
  • À chaque frappe dans le champ input, récupérer la valeur saisie
  • Si les noms contenus dans les
  • inclut la valeur saisie (en ignorant la casse), laisser l'élément visible, masquer les autres
  • On utilisera la classe Bootstrap "d-none" pour masquer les éléments
