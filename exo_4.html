Onglets dynamique (Tabs)

  • Objectif : Créer une navigation par onglets où le clic sur un titre affiche le contenu correspondant et masque les autres. L'exercice est basé sur l'HTML de Bootstrap, MAIS le code JS de Bootstrap n'est pas importé volontairement. Vous devez faire fonctionner les tab-pan par votre propre code JS.
  • Consignes :
  • Un clic su le bouton "First Tab" doit afficher le contenu de l'élément définit par le selecteur présent dans l'attribut : "data-bs-target"
  • Pour que le bon élément s'affiche il faut ajouter les classes CSS "show" et "active" sur celui-ci
  • Il faudra retirer les classes CSS "show" et "active" des autres div, ayant la classe "tab-pane"
